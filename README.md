# PadForge Downloads

Anonymous installer downloads for PadForge. The source code remains in the private [PadForge source repository](https://github.com/Pranav-Lejith/PadForge).

Each release includes installers for Debian and Ubuntu, Fedora, Arch Linux, Flatpak, and AppImage, plus the matching GPL-3 source archive. No GitHub account is required to download these public release assets.

See the source repository's [installation guide](https://github.com/Pranav-Lejith/PadForge/blob/main/docs/INSTALL.md) for one-line install commands. This mirror contains release assets only; it does not contain the application source in its Git history. The source archive is attached to each release to accompany the binaries.
